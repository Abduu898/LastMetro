# Paris scene assets

- `paris-street-background.png` is a clean, full-screen gameplay backdrop made to match the user's video reference. It has the Paris café, Eiffel Tower, riverside, métro entrance, street, and bridge railing, with no game HUD or moving gameplay objects. The renderer scales it to the game view and draws the runner, hazards, and pickups over it.
- `paris-composite.jpg` is the original labeled concept board, retained as a source reference.
- `paris-foreground.png` is a transparent crop from the concept board, retained for the earlier layered-scene experiment and possible future parallax work.

The new background is one complete illustration, so it is a stable first visual checkpoint rather than a seamless scrolling production scene. Separate layered street and station artwork can replace it when the Metro bonus stage is built.
